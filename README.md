# Печать героя

Веб-тренажёр слепой печати с упражнениями на русском и английском языках. Помогает тренировать скорость и точность, отслеживать прогресс и сравнивать результаты с другими игроками.

Проект создан для хакатона. Сервер, API и сайт запускаются одним приложением FastAPI.

**Адрес для публикации:** [blindtyping.codetimes.org](https://blindtyping.codetimes.org)

## Возможности

- **Четыре режима:** слова, предложения, код и специальные символы.
- **Русская и английская раскладки:** основные подписи экранной клавиатуры меняются при переключении RU/EN.
- **Подсказки при вводе:** текущий символ, нужная клавиша и палец.
- **Метрики тренировки:** слова и символы в минуту, точность, ошибки и серия правильных нажатий.
- **Игровой прогресс:** опыт, уровни, множители комбо и достижения.
- **Управление тренировкой:** пауза, продолжение, исправление через Backspace и перезапуск.
- **Личный профиль:** история, график результатов, время тренировок и трудные символы.
- **Таблица лидеров:** фильтры по скорости, точности и опыту за день, неделю и всё время.
- **Аккаунт:** регистрация, вход, выход и сохранение прогресса в SQLite.
- **Адаптивный интерфейс:** единая карточка игрока в шапке и короткие эффекты с поддержкой уменьшения движения.
- **Главная страница:** демонстрация набора текста с паузами, опечаткой и исправлением.

## Установка и запуск

Требуются **Python 3.10 или новее**, Git и современный браузер. Фронтенд не требует отдельной сборки.

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/dolikRJN/Hackatone.git
cd Hackatone
```

Дальнейшие команды выполняются из корня проекта.

### 2. Создайте окружение и запустите сервер

**Windows / PowerShell:**

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe -m uvicorn router.server:app --reload
```

Команды используют Python из виртуального окружения напрямую, поэтому запуск `Activate.ps1` не требуется.

**Linux / macOS:**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn router.server:app --reload
```

### 3. Откройте сайт

Перейдите на **http://127.0.0.1:8000/**.

| Страница | Адрес |
| --- | --- |
| Главная | http://127.0.0.1:8000/ |
| Вход и регистрация | http://127.0.0.1:8000/auth |
| Тренировка | http://127.0.0.1:8000/game |
| Профиль | http://127.0.0.1:8000/profile |
| Таблица лидеров | http://127.0.0.1:8000/leaderboard |
| Swagger UI | http://127.0.0.1:8000/docs |
| ReDoc | http://127.0.0.1:8000/redoc |

Флаг `--reload` включает перезапуск при изменении Python-кода. Чтобы остановить сервер, нажмите **Ctrl+C** в его терминале.

## Как пользоваться

1. Зарегистрируйтесь: укажите никнейм, email и пароль от 6 символов.
2. Откройте тренировку, выберите режим и язык.
3. Нажмите на текст и начните ввод. Используйте соответствующую раскладку ОС; для кода — английскую.
4. Исправляйте введённые символы через **Backspace**, вводите новую строку через **Enter**. При необходимости используйте кнопку паузы.
5. Допечатайте упражнение до конца. После сохранения появится сообщение о полученном опыте и новых достижениях.
6. Посмотрите историю и статистику в профиле, затем сравните результат в таблице лидеров.

Результат записывается после завершения упражнения. Перезапуск или смена режима до завершения начинают новую тренировку.

Переключатель RU/EN меняет язык упражнения и подписи экранной клавиатуры. Раскладку физической клавиатуры нужно переключать средствами операционной системы.

## База данных и настройки

При первом запуске приложение создаёт недостающие таблицы, уровни и достижения. В существующей базе добавляются необходимые поля; аккаунты и история не удаляются.

По умолчанию используется `SQLiteDB.db` в корне проекта. Готовые упражнения загружаются из `data.json`.

| Переменная окружения | По умолчанию | Назначение |
| --- | --- | --- |
| `TYPING_DB_PATH` | `SQLiteDB.db` в корне проекта | Путь к отдельной базе данных |
| `SITE_URL` | `https://blindtyping.codetimes.org` | Основной домен для canonical, Open Graph и sitemap |

Пример настройки в PowerShell перед запуском:

```powershell
$env:SITE_URL = "https://blindtyping.codetimes.org"
$env:TYPING_DB_PATH = "C:\data\typing\SQLiteDB.db"
.\venv\Scripts\python.exe -m uvicorn router.server:app --reload
```

Для отдельной БД заранее создайте родительскую папку. Переменные читаются при запуске процесса; после их изменения перезапустите сервер. Файл `.env` автоматически не загружается.

`generate_data.py` — дополнительный инструмент для обновления упражнений через локальную Ollama. Его Python-зависимость `ollama` устанавливается отдельно; название модели указано в самом скрипте.

## API

Все методы API используют префикс **`/api/v1`**. Сайт и API работают с одного адреса.

| Метод | Путь | Назначение |
| --- | --- | --- |
| `POST` | `/api/v1/auth/register` | Регистрация |
| `POST` | `/api/v1/auth/login` | Вход и получение токена |
| `POST` | `/api/v1/auth/logout` | Отзыв текущего токена |
| `GET` | `/api/v1/users/me` | Данные текущего пользователя |
| `GET` | `/api/v1/exercises/generate` | Генерация упражнения |
| `POST` | `/api/v1/stats/submit` | Сохранение результата |
| `GET` | `/api/v1/stats/summary` | Общая статистика |
| `GET` | `/api/v1/stats/history` | История тренировок |
| `GET` | `/api/v1/stats/error-analysis` | Частые ошибки |
| `GET` | `/api/v1/stats/achievements` | Каталог достижений |
| `GET` | `/api/v1/stats/achievements/my` | Достижения пользователя |
| `GET` | `/api/v1/stats/leaderboard` | Таблица лидеров |

Регистрация и вход возвращают `token`. Для запросов к профилю, личной статистике, сохранению результата и выходу передавайте заголовок:

```http
Authorization: Bearer <token>
```

В Swagger UI можно выполнить вход, скопировать токен из ответа и вставить его через **Authorize**. Сессия действует 7 дней и сохраняется при перезапуске сервера. Выход отзывает текущий токен.

Рейтинг «Сегодня» использует календарный день UTC, «Неделя» — последние 7 дней. Опыт за период показывает сумму опыта, заработанного за этот период.

## Проверки

Тесты создают временные базы и не изменяют рабочую `SQLiteDB.db`.

**Windows / PowerShell:**

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\venv\Scripts\python.exe -m unittest discover -s tests -v
```

**Linux / macOS:**

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m unittest discover -s tests -v
```

Проверяются регистрация и авторизация, изоляция данных пользователей, сохранение результатов, достижения, режимы упражнений, фильтры рейтинга, обновление старой схемы БД, маршруты страниц, редиректы и SEO-метаданные.

Перед слиянием ветки также проверьте в браузере сценарий: **регистрация → тренировка → сохранение → профиль → рейтинг → выход → повторный вход**.

## SEO и публикация

По умолчанию основной домен — **https://blindtyping.codetimes.org**. Для другого домена задайте `SITE_URL`.

- Главная и `/leaderboard` имеют уникальные заголовки, описания, canonical-ссылки, Open Graph и JSON-LD.
- `/robots.txt` содержит ссылку на `/sitemap.xml`; в карту включены только публичные страницы.
- Вход, игра, профиль, API и документация помечены `noindex`.
- `/static/img/social-preview.png` используется для предпросмотра ссылок.

На тестовом публичном стенде можно отключить индексацию, задав `SITE_URL` одному пробелу. Приложение удаляет пробелы и воспринимает значение как пустое:

```powershell
$env:SITE_URL = " "
```

После публикации настройте домен и HTTPS на хостинге. В Google Search Console и Яндекс Вебмастере подтвердите владение сайтом и отправьте карту:

```text
https://blindtyping.codetimes.org/sitemap.xml
```

## Частые вопросы

**Порт 8000 занят или появляется WinError 10013.** Остановите предыдущий экземпляр сервера через Ctrl+C или запустите приложение на другом порту:

```powershell
.\venv\Scripts\python.exe -m uvicorn router.server:app --reload --port 8001
```

В таком случае сайт откроется по адресу http://127.0.0.1:8001/.

**После обновления не видны изменения интерфейса.** Обновите страницу через Ctrl+F5, чтобы браузер заново загрузил CSS и JavaScript.

**Не находится модуль `router`.** Выполните команду запуска из корня репозитория, где находятся папки `router` и `template`.
